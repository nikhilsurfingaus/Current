# Screenshots

Add PNG captures here for the README and portfolio. Suggested filenames:

| File | What to capture |
|------|-----------------|
| `dashboard.png` | Dashboard with balance + recent activity |
| `accounts.png` | Accounts list |
| `transfer.png` | Transfer form |
| `payments.png` | Pay someone or payment history |
| `analytics.png` | Analytics charts |
| `goals.png` | Goals list |
| `loans.png` | Loans list or detail |
| `notifications.png` | Notification dropdown open |
| `mobile.png` | Mobile viewport (dashboard or nav drawer) |
| `login.png` | Login page |

## How to capture

1. Log in at https://current-au.vercel.app with the [demo account](../DEMO.md)
2. Use browser dev tools → toggle device toolbar for mobile
3. Save PNGs into this folder
4. Reference in root `README.md`:

```markdown
![Dashboard](docs/screenshots/dashboard.png)
```

Placeholders are fine until you add real images — the docs structure is ready.
